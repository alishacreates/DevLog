# DevLog MVP Scope

## Goal

Enable developers to document their development journey and interact with other developers through the work they are building.

## Included

- Authentication
- User Profiles
- Create / View / Edit / Delete Projects
- Create / View / Edit / Delete DevLogs
- Public / Private Visibility
- Community Feed
- Likes
- Comments
- Follow Users
- User Search

## Not Included

- Messaging
- Notifications
- AI
- Hackathons
- Communities
- Team Finder
- Recruiter Dashboard

## Definition of Done

A user can:

- Sign up using Google or GitHub
- Complete onboarding
- Create and edit a developer profile
- Create a project
- Edit or delete their project
- Publish DevLogs for that project
- Edit or delete their DevLogs
- Control public/private visibility
- Discover public DevLogs in the feed
- Like DevLogs
- Comment on DevLogs
- Follow and unfollow developers
- Search for other developers
- Visit another developer's profile
- Use all core workflows on mobile and desktop

The MVP is complete when this entire loop works reliably:

Developer signs in
→ creates a project
→ posts progress
→ another developer discovers it
→ likes/comments/follows
→ developer continues building
→ posts another DevLog
