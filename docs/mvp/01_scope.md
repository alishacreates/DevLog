# DevLog MVP Scope

## Goal

Enable student developers to document their development journey.

## Included

- Authentication
- User Profiles
- Create Projects
- Create DevLogs
- Feed
- Likes
- Comments
- Follow Users
- User Search

## Not Included

- Messaging
- Notifications
- AI
- Hackathons
- Communities
- Team Finder
- Recruiter Dashboard

## Definition of Done

A user can:

- Sign up
- Create a profile
- Add a project
- Post a DevLog
- Like/comment/follow
- Discover other developers
