# DevLog SEO Plan

## Purpose

This document defines the SEO strategy for DevLog across two stages:

1. **Public landing-page preview**
2. **MVP and post-launch growth**

The goal is to keep SEO simple during the preview while building a foundation that can scale once public projects, DevLogs, and developer profiles become available.

---

# 1. SEO Goals

DevLog should make it easy for search engines and social platforms to understand:

- What DevLog is
- Which pages are public
- Which pages should not be indexed yet
- What title and description should appear in search results
- What image and copy should appear when DevLog is shared on LinkedIn or other social platforms
- How public developer content should be indexed after launch

The current focus is **technical SEO**, not aggressive keyword targeting.

---

# 2. Current Stage: Landing Preview

## Public pages

The following pages are intended to be publicly accessible and indexable:

- `/`
- `/design`
- `/built-by`

## Non-public / unfinished routes

The following routes should not be indexed during the preview stage:

- `/coming-soon`
- `/sign-in`
- `/feed`
- `/projects`
- `/projects/*`
- `/devlogs/*`
- `/profile`
- `/profile/*`
- `/onboarding`
- `/api/*`

The preview deployment redirects unfinished product routes to `/coming-soon`.
