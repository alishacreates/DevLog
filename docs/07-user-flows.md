# MVP User Journey

1. User signs up.
2. Completes profile.
3. Creates first project.
4. Publishes first DevLog.
5. Receives engagement.
6. Discovers other developers.
7. Continues sharing progress.

The goal of the MVP is to make sharing progress and discovering other builders as simple as possible while laying the foundation for future collaboration features.
