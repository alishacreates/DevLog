# BuildLog

BuildLog is a developer-focused social platform where programmers can share project progress, document technical challenges, showcase their work, and connect with other builders.

## Vision

Most developers build projects but rarely document their journey.

BuildLog helps developers:

- Share project updates
- Maintain a public engineering journal
- Showcase technical work
- Discover other developers
- Find collaborators
- Build a stronger portfolio

## MVP Features

### Authentication
- GitHub OAuth
- Protected routes

### Profiles
- Developer profile
- Bio
- Skills
- GitHub link

### Posts
- Create build logs

- View developer profiles

### Social Features
- Likes
